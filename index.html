Fábrica de Vídeos

Ferramenta pessoal que produz, publica e acompanha vídeos educativos nos canais do YouTube do próprio dono.

O que o app faz

  • Produz vídeos curtos e longos (roteiro, narração, animação e legendas) para os canais do dono.
  • Envia os vídeos prontos para esses canais, com título, descrição, thumbnail, legendas e agendamento.
  • Lê as métricas dos próprios canais (visualizações, tempo assistido, retenção) para gerar um painel e relatórios locais.

Quem usa

O app não é oferecido ao público. Só o dono dos canais o usa, no próprio computador, e só acessa os canais em que ele mesmo fez login e autorizou o acesso pela tela do Google.

Dados do Google

O uso de dados do YouTube é descrito na Política de Privacidade. O app segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
